# Το πρόβλημα του Βραχυστόχρονου – κώδικας και δεδομένα

Συνοδευτικό υλικό της μαθητικής εργασίας «Το πρόβλημα του Βραχυστόχρονου: από τη θεωρία του
Bernoulli στην πειραματική διερεύνηση» (Π. Καφετζής, Γ. Α. Παυλίδης· επιβλέπουσα: Ι. Φλεμοτόμου,
1ο Πρότυπο Γυμνάσιο Αθηνών, 5ο Μαθητικό Συνέδριο Έρευνας και Επιστήμης).

Τρεις σφαίρες από χάλυβα (Ø15 mm) αφήνονται ταυτόχρονα σε τρεις τροχιές με κοινή αρχή και κοινό
τέλος: **ευθεία**, **κυκλοειδής**, **πολυωνυμική 6ου βαθμού**. Τρεις αισθητήρες υπερύθρων (TCRT5000)
και ένα Arduino καταγράφουν τη στιγμή άφιξης κάθε σφαίρας. Συγκρίνουμε τις **διαφορές** χρόνων άφιξης.

## Περιεχόμενα

| Αρχείο | Περιγραφή |
|---|---|
| `brachistochrone_w.button.ino` | Χρονόμετρο Arduino: το κουμπί ξεκινά το `micros()`, κάθε αισθητήρας (ακροδέκτες 7, 6, 5 = ευθεία, κυκλοειδής, πολυωνυμική) καταγράφει την πρώτη ανίχνευση. |
| `measurements.csv` | Οι 18 δοκιμές: χρόνοι άφιξης σε ms από την εκκίνηση του χρονομέτρου, χωρίς καμία διόρθωση. |
| `extract_profiles.py` | Εξαγωγή των προφίλ z(y) των τριών αυλακιών από το STL. |
| `profiles.csv` | Αποτέλεσμα της εξαγωγής: `y_mm, z_straight_mm, z_cycloid_mm, z_polynomial_mm`. |
| `model_times.py` | Αριθμητικός υπολογισμός των θεωρητικών χρόνων (Tε, Tκ, Tπ). |
| `statistics_analysis.py` | Μέσες τιμές, SEM, διαστήματα εμπιστοσύνης 95%, έλεγχος προσήμου, συσχέτιση. |
| `brachistochrone v.1.jpg`, `brachistochrone v.2.jpg`, `brachstochrone v.2.mp4` | Φωτογραφίες και βίντεο της διάταξης. |

## Εκτέλεση

```
pip install -r requirements.txt
python model_times.py              # Tε ≈ 365, Tκ ≈ 299, Tπ ≈ 305 ms  (z0 = 147,1 mm)
python statistics_analysis.py      # N = 18: tε−tκ = 66,6 ± 2,4 ms κ.λπ.
```

Για να ξαναβγούν τα προφίλ από το STL (το αρχείο δεν περιλαμβάνεται εδώ, βλ. παρακάτω):

```
python extract_profiles.py Brachistochrone_run.stl profiles.csv
```

## Μοντέλο (σύνοψη)

- Το κέντρο της σφαίρας κινείται σε καμπύλη που απέχει r = 7,5 mm από τον πυθμένα του αυλακιού.
- Εκκίνηση χωρίς ταχύτητα με το κέντρο στα z0 = 147,1 mm (≈ 6 mm κάτω από την κορυφή 153,1 mm
  του STL). Το z0 είναι γνωστό μόνο κατά ±1 mm· το script τρέχει για 146,1 / 147,1 / 148,1 mm.
- Κύλιση συμπαγούς σφαίρας: v = √(2gh/k), k = 1,4 (υπόθεση επαφής σε ένα σημείο, δεν επαληθεύτηκε).
- Χρόνος: T = Σ ds / v πάνω στην καμπύλη του κέντρου.

## Σημειώσεις και περιορισμοί

- Οι χρόνοι `measurements.csv` είναι στιγμές άφιξης ως προς την εκκίνηση του χρονομέτρου, όχι
  χρόνοι κατάβασης: η στιγμή απελευθέρωσης (χειροκίνητη) δεν μετρήθηκε.
- Η στιγμή καταγραφής εξαρτάται από το όριο ανίχνευσης κάθε αισθητήρα (1 mm ≈ 0,7 ms στα 1,4 m/s).
- Τα διαστήματα εμπιστοσύνης αφορούν μόνο τη διασπορά των επαναλήψεων.
